Setup steps
  1. Flash firmware/bridge/bridge.ino to the Nano with the PCA9685 on A4 and A5. Plug the leg servos into channels 0 to 4.
  2. Connect, then choose Horn mode. Every servo holds 90°. Fit the horns with each joint straight.
  3. Calibrate each joint: set the centre, then the two mechanical stops.
  4. Choose Run and try Squat and Sweep. Compare the real leg with the picture and flip any joint that disagrees.
